# Changelog

## 0.1.0 (2026-10-12)

- First release: search sheets with fzf (`keysheet`), print matches (`keysheet WORD…`),
  `--all`, `--edit`, `--check`, `--examples`, `--init zsh|bash`, `--format`.
- Sheets from the folders in `KEYSHEET_PATH` (default `~/.config/keysheet`).
- Example sheets for the shell, tmux and git.
